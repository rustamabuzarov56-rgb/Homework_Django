# Проект представляет собой веб-приложение на Django для управления каталогом товаров. 

## Технологии
* Python 3.13
* Django 6.0.3
* Bootstrap 5
* GitFlow

## Структура проекта
* `config\` - основные настройки проекта
* `catalog\` - приложение для работы с товарами и контактами
* `templates\` - HTML-шаблоны страниц

## Наполнение базы данных

Для проекта подготовлены фикстуры с тестовыми данными (категории и продукты). 
### Фикстуры можнно выгрузить двумя способами:

1. Через стандартную команду Django:
   ```python manage.py loaddata catalog-fixture.json```
2. Через кастомную команду:
   ```python manage.py add_products```

## Медиа-файлы

В проекте настроена работа с изображениями продуктов:
- Загруженные изображения сохраняются в директорию `media/`.
- В режиме разработки (`DEBUG=True`) раздача медиа-файлов осуществляется встроенным сервером Django.

## Установка и запуск

1. **Клонируйте репозиторий**

```git clone <ссылка_на_ваш_репозиторий>```

2. **Настройте виртуальное окружение**

```python -m venv venv```

3. **Установите зависимости**

```pip install django```

4. **Запустите сервер**

```python manage.py runserver```

## Зависимости

Установка библиотеки psycopg2-binary:

```pip install psycopg2-binary```

```pip freeze > requirements.txt```

## Разработка (GitFlow)
В проекте используются следующие ветки:

* main — стабильная версия.
* develop — основная ветка разработки.
* feature/* — ветки для выполнения домашних заданий.
